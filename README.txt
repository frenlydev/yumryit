# YUMRYIT website

A responsive, performance-optimized static site for GitHub Pages.

## Structure
- `index.html` — complete website
- `assets_optimized/` — compressed WebP imagery used by the page

## Deploy
Upload `index.html` and the entire `assets_optimized` folder to the root of your GitHub Pages repository, then enable Pages from the repository's Settings.

## Mobile & performance
The site includes:
- Mobile-first responsive breakpoints
- Accessible touch targets
- Collapsible mobile navigation
- Lazy-loaded below-the-fold images
- Responsive `srcset` image selection
- Compressed WebP imagery
- Reduced-motion support
- Direct WhatsApp enquiry link
- No framework or build process

The optimized image set reduces the current image payload by roughly 88% compared with the original uploaded images.

## Later image updates
Add new optimized WebP files to `assets_optimized/` and update the corresponding image paths in `index.html`. For best performance, provide 480px, 768px and larger variants where practical.
